# Introduction to IonAPI

Welcome to the official documentation for **IonAPI**, a comprehensive library designed to simplify modern Minecraft plugin development.

IonAPI provides a fluent, modern API for handling complex tasks like GUIs, NPCs, Database connections, and multithreading, while maintaining compatibility with both **Paper** and **Folia**.

## Key Features

*   **Fluent GUI Builder**: Create complex menus with click handlers and animations in seconds.
*   **Packet-Based NPCs**: Create lightweight NPCs without NMS headaches.
*   **Database ORM**: Simple connection pooling and query execution.
*   **Task Chains**: Readable sync/async task execution.
*   **Modern Items**: `IonItem` builder with MiniMessage support.
*   **Dependency Injection**: Built-in service locator pattern.
*   **Folia Support**: Native regionized scheduler support.

## Project Goal

The goal of IonAPI is to reduce boilerplate code and allow developers to focus on features rather than internal server mechanics.

# IonGui Module

The **IonGui** module provides a powerful, fluent API for creating and managing usage Minecraft GUIs (Menus).

## Features
*   **Fluent Builder**: Chain methods to build complex GUIs.
*   **Click Handlers**: Define logic right where you define the item.
*   **Animations**: Built-in support for animated items.
*   **Auto-Updating**: Automatically refresh the GUI at a set interval.
*   **Drag & Drop Control**: Granular control over player interactions.

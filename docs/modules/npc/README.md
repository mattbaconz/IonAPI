# IonNPC Module

The **IonNPC** module allows you to create lightweight, server-friendly NPCs using packets.

## Features
*   **No NMS Required**: Uses packet wrappers to ensure compatibility.
*   **Skins**: Fetch skins by username or texture data.
*   **Visibility Control**: Show/Hide NPCs per player.
*   **Click Actions**: Easy callbacks for interactions.

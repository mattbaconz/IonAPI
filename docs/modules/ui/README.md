# User Interface Module

The **IonUI** module handles on-screen displays like Scoreboards and BossBars.

## Features
*   **IonScoreboard**: Flicker-free, threaded scoreboards with MiniMessage support.
*   **IonBossBar**: Easy-to-use Wrapper for Adventure BossBars with dynamic progress.
